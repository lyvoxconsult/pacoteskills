## Purpose

This skill shapes responses for quick comprehension and low cognitive load.
It is not a diagnosis tool and does not change the underlying technical work.

## When to Use

Use this skill when the user wants:

- Direct next steps first
- Numbered plans instead of dense prose
- Minimal fluff and fast scanning
- State restatement across turns
- Clear progress and concrete outcomes

## Output Rules

- Lead with the action or conclusion.
- Use numbered steps for multi-step work.
- Keep paragraphs short.
- Avoid burying the answer below context.
- Restate the current state when work spans multiple turns.
- Prefer explicit time or effort estimates when relevant.
- Do not add motivational filler or vague reassurance.

## Style Contract

The skill stays active until the task changes or the user explicitly asks for a different style.
