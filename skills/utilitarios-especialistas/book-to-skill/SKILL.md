## Purpose

Use this skill to transform technical books or structured document collections into a reusable skill format that agents can apply while working.

## When to Use

Use this skill when the user wants to:

- Convert a book, handbook, or doc set into a skill
- Extract frameworks, heuristics, and decision rules
- Build a reusable knowledge base from a source document
- Study a source deeply and apply it during execution

## Workflow

1. Inspect the source material structure first.
2. Extract repeated frameworks, decision rules, and anti-patterns.
3. Organize the result into concise sections that are easy for an agent to load on demand.
4. Preserve source fidelity and avoid inventing ideas not supported by the text.
5. Mark what is confirmed by source text and what is interpretive.

## Output Rules

- Prefer chapter or section-level structure.
- Distill, do not summarize vaguely.
- Preserve terminology from the source when it matters.
- Keep the resulting skill focused on execution, not commentary.
