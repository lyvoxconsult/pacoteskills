# Regras Locais - Ultra Tokens

Quando esta pasta for usada como pacote de skills:

- Responder em pt-BR quando o usuario nao pedir outro idioma.
- Antes de tarefas significativas, usar `find-skills` para localizar skills aplicaveis.
- Usar `i-have-adhd` para manter andamento curto, numerado e orientado a acao.
- Usar `devpromptarchitect` ou `dev-prompt-architect` quando o pedido precisar virar prompt tecnico.
- Usar `zipai-optimizer`, `context-optimization`, `context-compression` e `prompt-caching` para reduzir tokens por tarefa.
- Usar `context-guardian`, `context-management-context-save` e `context-management-context-restore` em tarefas longas ou com risco de compactacao.
- Coletar contexto real antes de responder, mas limitar buscas amplas e loops.
- Nao gravar segredos, tokens, cookies, sessoes, bancos ou logs reais em arquivos versionados.
- Nao declarar sucesso sem evidencia de validacao.
