# 🎨 Frontend Skills — Interfaces Visualmente Deslumbrantes

Esta skill define os padrões operacionais para construir interfaces de altíssima fidelidade estética, fluidez interativa e consistência visual premium.

---

## 💎 Padrões Visuais Requeridos (Visual Premium)

1. **Aesthetics First (Estética em Primeiro Lugar):**
   - Evite cores cruas e básicas. Crie paletas harmoniosas com base em variáveis HSL ou cores de marca curadas.
   - Suporte nativo a **Dark Mode** refinado deve ser planejado e implementado por padrão.
   - Aplique gradientes lineares ou radiais suaves e sutis para adicionar profundidade e sofisticação às interfaces.
   - Utilize a fonte **Inter** ou do ecossistema do Google Fonts para todas as interfaces.

2. **Micro-interações e Dinamismo:**
   - Adicione transições CSS suaves (`transition: all 0.3s ease`) em botões, links, cards e inputs de texto.
   - Aplique efeitos interativos hover e active coerentes (ex: leve alteração de opacidade, escala ou cor de fundo).
   - Use bibliotecas de animação de alta performance apenas quando justificado, mantendo a leveza do carregamento.

---

## 🛠️ Diretrizes de Estruturação e Boas Práticas

- **Semântica HTML5:** Utilize elementos adequados (`<header>`, `<main>`, `<nav>`, `<article>`, `<footer>`) para garantir acessibilidade e SEO.
- **CSS Modular:** Favoreça o uso de CSS limpo, de fácil manutenção, variáveis globais organizadas e evite a criação de gambiarras estruturais ad-hoc.
- **Responsividade Nativa:** Toda interface deve ser planejada usando metodologias Mobile-First, com breakpoints claros para resoluções de telas de smartphones, tablets e desktops de alta resolução.
- **Validação de Formulários:** Sempre aplique validações ricas tanto no lado do cliente (visual/UX) quanto antes do disparo para o backend.
